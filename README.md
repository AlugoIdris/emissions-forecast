## Models

| Model | Role | Uncertainty |
|---|---|---|
| **N-HiTS** | Hierarchical time-series forecasting | Q10/Q90 confidence intervals |
| **XGBoost-Quantile** | Operational feature forecasting | Q10/Q50/Q90 quantile regression |
| **BNN (MC Dropout)** | Temporal pattern + epistemic uncertainty | Monte Carlo samples (N=100) |
| **Meta-Learner Ensemble** | Stacking (Ridge + ElasticNet + GBM + RF) | Inverse-MAPE weighted blend |

## Reproducibility

All random seeds are fixed via `config.RANDOM_SEED = 42`.  
All hyperparameters are centralised in `config.py`.  
The notebook `01_run_pipeline.ipynb` reproduces all figures and result CSVs.
